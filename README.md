# Поиск по текстовым PDF-файлам

Учебный проект по дисциплине «Проектно-исследовательская работа». Кейс № 10 — «Поисковик».

Цель проекта — разработать HTTP-сервер с REST API для поиска информации в текстовых PDF-файлах.

## Возможности

- Поиск по одному или нескольким словам без учёта регистра.
- Чтение PDF-файлов с помощью библиотеки pypdf.
- Настройка каталогов поиска через YAML-файл.
- Индексация новых и изменённых документов при запуске.
- Хранение извлечённого текста в MongoDB.
- Ранжирование документов по модели TF-IDF.
- Возврат до 10 наиболее релевантных результатов.

## Установка и запуск

Для работы необходимы Python и запущенный сервер MongoDB на `localhost:27017`.

Клонировать репозиторий:

```bash
git clone https://github.com/melipo-a/pdf-search.git
cd pdf-search
```

Создать виртуальное окружение и установить зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

По умолчанию документы ищутся в папке `pdfs`. Каталоги можно изменить в файле `config.yml`:

```yaml
directories:
  - pdfs
```

Поместить PDF-файлы в выбранный каталог и запустить сервер:

```bash
python main.py
```

Сервер будет доступен по адресу `http://localhost:8008`.

## REST API

### GET /documents

Поиск документов по обязательному параметру `q`.

Пример запроса:

```bash
curl -G --data-urlencode "q=охрана труда" http://localhost:8008/documents
```

Успешный ответ — `200 OK`:

```json
[
  {
    "file": "safety.pdf"
  },
  {
    "file": "manual.pdf"
  }
]
```

Результаты отсортированы по убыванию релевантности. Поле `file` содержит путь к документу относительно настроенного каталога.

Если документы не найдены, возвращается пустой массив `[]`.

Если запрос отсутствует или пустой, сервер возвращает `400 Bad Request`:

```json
{
  "error": "Укажите поисковый запрос"
}
```

## Тестирование

Запуск тестов:

```bash
python -m pytest -v
```

Проверка покрытия:

```bash
python -m pytest --cov=pdf_search --cov=main --cov-branch --cov-report=term-missing
```

Проверка стиля кода:

```bash
python -m flake8 main.py pdf_search tests
```

Для тестирования MongoDB используется библиотека `mongomock`. Автоматические проверки настроены через GitHub Actions.
