# Поиск по текстовым PDF-файлам

Проект по дисциплине «Проектно-исследовательская работа». Кейс № 10 — «Поисковик».

Цель проекта — разработать HTTP-сервер с REST API для поиска по текстовым PDF-файлам.

## REST API

### Поиск документов

| Действие | URL | Метод | Описание запроса и ответа |
| --- | --- | --- | --- |
| Поиск документов | `/documents` | GET | Принимает поисковую фразу через параметр `q`. Возвращает до 10 наиболее релевантных PDF-файлов в формате JSON. |

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| `q` | string | Да | Непустая поисковая фраза из одного или нескольких слов. |

Пример запроса:

`GET /documents?q=охрана%20труда`

### Ответ 200 OK

Сервер возвращает JSON-массив найденных документов, отсортированных по убыванию релевантности на основе TF-IDF.

Пример ответа:

~~~json
[
  {
    "file": "safety.pdf"
  },
  {
    "file": "manual.pdf"
  }
]
~~~

Поле `file` содержит путь к PDF-файлу относительно каталога поиска.

Если подходящих документов нет, возвращается пустой массив:

~~~json
[]
~~~

### Ответ 400 Bad Request

Возвращается, если параметр `q` отсутствует, пустой или содержит только пробелы.

Пример ответа:

~~~json
{
  "error": "Укажите поисковый запрос"
}
~~~

## Принцип работы

- Каталоги для поиска задаются в YAML-файле конфигурации.
- При запуске сервер проверяет наличие новых PDF-файлов и при необходимости индексирует их.
- Текст документов извлекается с помощью библиотеки `pypdf`.
- Поиск выполняется без учёта регистра.
- Документы ранжируются на основе TF-IDF.
- Сервер возвращает не более 10 наиболее релевантных документов.
